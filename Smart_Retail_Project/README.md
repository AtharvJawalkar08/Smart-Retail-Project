# 🛍️ Smart Retail Restocking Dashboard

An AI-powered retail inventory management system that predicts weekly product demand and automates restocking decisions using Python, Streamlit, SQLite, and R.

---

## 📁 Project Structure

```
Smart_Retail_Project/
│
├── app.py                  # Main Streamlit dashboard (run this to launch the app)
├── setup_database.py       # Creates the SQLite database and all tables
├── insert_mock_data.py     # Seeds the database with sample products and sales
├── train_ai_model.py       # Standalone AI model training and prediction script
├── analyze_trends.R        # R script for SQL-based trend analysis and charting
├── retail_store.db         # Pre-built SQLite database file
└── Rplots.pdf              # Output chart generated by the R script
```

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Python 3.8+
- R (for trend analysis script)

### Install Python Dependencies

```bash
pip install streamlit pandas scikit-learn
```

### Install R Dependencies

Open R or RStudio and run:

```r
install.packages("RSQLite")
```

---

## ⚙️ Setup & Run

### Step 1 — Create the Database

Run this once to set up the SQLite database and create all required tables:

```bash
python setup_database.py
```

### Step 2 — Seed Sample Data

Populate the database with 3 products and 5 days of sales history:

```bash
python insert_mock_data.py
```

### Step 3 — Launch the Dashboard

Start the Streamlit web app:

```bash
streamlit run app.py
```

The app will open automatically in your browser at `http://localhost:8501`.

## 🧠 How It Works

### Dashboard (`app.py`)

The Streamlit dashboard gives store managers a single-page view of:

| Feature | Description |
|---|---|
| **Product Selector** | Dropdown to choose any product from the database |
| **Stock Metrics** | Current stock, safety buffer, and AI-predicted demand |
| **Shelf Capacity Bar** | Visual progress bar showing stock health (🔴 / 🟡 / 🟢) |
| **Restock Advisory** | Automated order recommendation based on predicted deficit |
| **Sales Chart** | Historical demand trend line graph |
| **Shipment Simulator** | Button to simulate receiving +50 units into the warehouse |

### AI Model (`train_ai_model.py`)

- Loads sales transaction history from the SQLite database
- Converts calendar dates into numeric day counters (Day 1, Day 2, ...)
- Trains a **Linear Regression** model (scikit-learn) on quantity sold vs. day number
- Predicts next week's demand (Day 8) for each product

### Trend Analysis (`analyze_trends.R`)

- Connects directly to `retail_store.db` using `RSQLite`
- Runs a SQL query to aggregate total daily sales across all products
- Renders a line chart of daily demand trends saved as `Rplots.pdf`

## 🗄️ Database Schema

### `products`
| Column | Type | Description |
|---|---|---|
| `product_id` | INTEGER (PK) | Unique product identifier |
| `product_name` | TEXT | Display name (e.g., "Organic Milk") |
| `category` | TEXT | Product category (e.g., "Dairy") |
| `price` | REAL | Unit price |

### `sales_transactions`
| Column | Type | Description |
|---|---|---|
| `transaction_id` | INTEGER (PK, AUTO) | Auto-incremented receipt ID |
| `product_id` | INTEGER (FK) | References `products.product_id` |
| `quantity_sold` | INTEGER | Units sold in this transaction |
| `sale_date` | TEXT | Date of sale in `YYYY-MM-DD` format |

### `inventory_levels`
| Column | Type | Description |
|---|---|---|
| `product_id` | INTEGER (PK, FK) | References `products.product_id` |
| `current_stock` | INTEGER | Units currently on the shelf |
| `minimum_required` | INTEGER | Safety buffer threshold for reorder alerts |

## 📌 Notes

- The `retail_store.db` file is already pre-built and ready to use. You can skip Steps 1 and 2 if you want to use the existing data.
- Re-running `insert_mock_data.py` multiple times will add duplicate sales records. Use `INSERT OR IGNORE` safe guards in the products and inventory tables to prevent duplicate entries there.
- The Streamlit shipment simulator writes live changes to `retail_store.db`. Restart the app to see updated stock levels reflected in the dashboard.
